# KinemIQ combat motions

Sources:
- https://kinemiq.app/studio/
- https://kinemiq.app/free-fighting-animations/
- https://kinemiq.itch.io/free-game-animations

Obtain the free CC0 combat GLBs through KinemIQ, or export punch / kick / hit moves from Studio. The starter game has procedural attacks for immediate testing. To apply a KinemIQ animation to VR_Avatars' Sketchfab skeletons, upload the target character into Studio, apply/retarget clips, export a baked GLB and put it in `public/models/` under the expected filename.

Licences differ by source: Quaternius CC0 (no credit), ACCAD CC BY 3.0 (credit), 100STYLE CC BY 4.0 (credit). Refer to each exported clip's own attribution.
